# T0083 Automated Audit Review readme
By applying of anomaly detection (identification of observations, events or data points that deviate from what is usual, standard or expected, making them inconsistent or irregular) techniques, we aim to help customers meet these needs by increasing confidence in their system and proactively detect these irregularities.

Some key features of (but not limited to):                    
Rules-based Anomaly Detection - Detecting irregularities/anomalies using rules-based (customer-configurable rules) techniques. 
    - Time-based rules - Detecting irregularities/anomalies using time-based techniques (Aims to address recent changes to Annex 11 - GMP for medicinal products - Computerized systems) .

Machine Learning-based Anomaly Detection - Detecting irregularities/anomalies using algorithms and sophisticated techniques.
    - Enhanced activity log configuration for the detection of irregular/suspicious user activity.
